キーワード調べ（個人用ツール）

Keyword Research (personal tool)

このツールについて

このツールは、運営者が自分の SNS（Threads）の投稿づくりのために使う、個人用のツールです。一般には公開・提供していません。

運営者自身の Google 広告アカウントで、Google Ads API の「キーワードプランナー」（関連するキーワードと、月間の検索数のめやす）を呼び出し、宿や商品について、どんなことが多く調べられているかを確かめます。

  • 使うのは、運営者自身の Google アカウントと Google 広告アカウントだけです。
  • 広告の作成・変更・配信は行いません（キーワードのデータを読むだけです）。
  • ほかの人の Google アカウントやデータには、アクセスしません。

About

This is a personal, internal tool used only by its operator to plan posts for the operator's own social media account. It calls the Google Ads API Keyword Planner (KeywordPlanIdeaService) with the operator's own Google Ads account to see related keywords and approximate monthly search volumes. It does not create, change, or serve ads, and it does not access any other user's data. It is not offered to the public.
