プライバシーポリシー

キーワード調べ（個人用ツール）／制定日：2026年11月23日

1. 対象

このポリシーは、個人用ツール「キーワード調べ」（以下「本ツール」）が、Google のサービスから受け取る情報の扱いを定めます。本ツールを使うのは運営者本人だけです。

2. 受け取る情報

  • 運営者が Google アカウントでログインして許可したときに発行される、アクセス用の情報（OAuth のトークン）
  • Google Ads API のキーワードプランナーが返す、キーワードの候補と、月間の検索数のめやす

運営者以外の人の個人情報は、受け取りません。

3. 使い方

受け取った情報は、運営者自身の SNS の投稿づくりのために、どんなことが多く調べられているかを確かめる目的だけに使います。広告の作成・変更・配信には使いません。

4. 保管

  • アクセス用の情報（トークン）は、運営者のパソコンの中だけに保管し、公開の場所（ウェブサイト、ソースコード、共有のファイル）には置きません。
  • キーワードのデータは、運営者のパソコンと、運営者の Google スプレッドシートに保存することがあります。

5. 第三者への提供

受け取った情報を、第三者に売ったり、渡したり、広告のために使ったりしません。

6. Google API サービスのユーザーデータに関するポリシー

本ツールが Google API から受け取った情報の使用は、限定使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに従います。

7. 許可の取り消し

本ツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」の設定（https://myaccount.google.com/connections）から、いつでも取り消せます。

8. 変更

このポリシーを変えるときは、このページを更新します。

9. お問い合わせ

本ツールの Google OAuth 同意画面に表示している、連絡先のメールアドレスまでお願いします。

Privacy Policy (English summary)

This personal tool is used only by its operator. It receives OAuth tokens and Google Ads API Keyword Planner data (keyword ideas and approximate search volumes) for the operator's own Google Ads account. The data is used only to plan the operator's own social media posts. Tokens are stored only on the operator's computer. Data is not sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/connections.
